# Behavioral Rules

- **CRITICAL**: ห้ามทำการทดสอบยิง Push Notification (LINE Push Message หรือการแจ้งเตือนใดๆ) ไปยังกลุ่มผู้ใช้งานภายนอกหรือผู้ใช้ทดสอบโดยไม่ได้รับคำสั่งอย่างชัดเจนจากผู้ใช้ (Developer) เด็ดขาด
- **DEPLOYMENT**: โปรเจกต์นี้ไม่มีสคริปต์ deploy (เช่น deploy.sh) ให้ใช้วิธี git push ขึ้น origin main เพื่อทำการ deploy อย่างเดียว ห้ามมองหาสคริปต์ deploy
- **TIMEZONE**: ข้อมูลวันและเวลาที่บันทึกใน SQL Server ถูกบันทึกเป็นเวลาประเทศไทย (Bangkok Time) ตรงๆ แต่ mssql driver จะแปลงส่งออกมาโดยเติม Z (UTC) มาด้วยเสมอ ส่งผลให้ฟังก์ชัน `new Date()` บน Client ของผู้ใช้ในไทยจะแปลงเวลาบวกเพิ่มอีก 7 ชั่วโมง (Double offset) ดังนั้น เมื่อจะแสดงเวลาในหน้าเว็บ ให้จัดรูปแบบเวลา (Format Date/Time) ด้วย `timeZone: 'UTC'` หรือใช้ฟังก์ชันดึงค่า UTC โดยตรง (เช่น `getUTCDate()`, `getUTCHours()`) เท่านั้น ห้ามลืมเด็ดขาด!
- **DATABASE_SAFETY**: ห้ามเขียนสคริปต์รันทดสอบเพื่อทำการเขียน แก้ไข หรือลบข้อมูล (เช่นคำสั่ง INSERT, UPDATE, DELETE) บนฐานข้อมูลจริงผ่านฝั่ง Command Line โดยเด็ดขาด ห้ามทำจำลองรัน API ยิงแก้ไขหรือลบรายการใบงานจริง การทดสอบการบันทึกหรืออัปเดตข้อมูลจะต้องกระทำผ่าน UI หน้าเว็บโดยผู้ใช้งานจริงเท่านั้น
- **DATA_PRIVACY**: การแสดงผลชื่อบุคคล (พนักงานผู้บันทึก, ผู้ตรวจเช็ค, คนขับ, และลูกค้า/ผู้เช่า) บน UI หน้าเว็บทุกหน้า (รวมถึง Timeline, ประวัติการยึดรถ, ประวัติการย้ายรถ, บันทึกโน้ต) ให้แสดงเฉพาะ **ชื่อต้น** เท่านั้น (ไม่แสดงนามสกุล) โดยใช้ฟังก์ชัน Masking (เช่น `maskStaffName`, `maskFullName`) ห้ามแสดงนามสกุลเต็มออกมาบนหน้าเว็บเพื่อความปลอดภัยของข้อมูลส่วนบุคคล
- **GROUP_CHAT_CONTROL**: การตอบคำถามของ Butter ในกลุ่ม LINE ถูกควบคุมด้วย field `enableChat` (default: `true`) ใน LineGroup:
  - **enableChat = true**: Butter ตอบคำถามได้เมื่อถูกเรียก (ต้องพิมพ์ "butter" นำหน้า หรือ @mention Bot)
  - **enableChat = false**: Butter จะไม่ตอบคำถามทั่วไป ทำเฉพาะ auto-detection (Gate Log / Claim Log) เท่านั้น
  - **การตั้งค่า**: ตั้งค่าได้ที่หน้า Settings บนเว็บ Dashboard เท่านั้น
  - **กลุ่ม Gate Log / Claim Log**: ควรตั้ง `enableChat = false` เพื่อไม่ให้ Butter ตอบคำถามทั่วไปในกลุ่มเหล่านี้
- **GATE_LOG_MONITOR**:
  - **License Plate Normalization**: เมื่อบันทึกหรือค้นหาทะเบียนรถ ให้ normalize ให้อยู่ในฟอร์แมตมาตรฐาน `[หมวดตัวอักษร]-[ตัวเลข]` เสมอ (เช่น `ทอ-1234`, `1กก-1234`) เพื่อให้การค้นหาจับคู่เข้า-ออกเป็นมาตรฐานเดียวกัน
  - **New Car Tracking (รถใหม่ไม่มีทะเบียน)**: รถใหม่ที่ไม่มีทะเบียนจะบันทึกเป็น `VehicleRef = 'รถใหม่'` โดยใช้ระบบ `QuantityIn` (จำนวนเข้า) และ `QuantityOut` (จำนวนออก) ใน 1 เรคคอร์ด และเมื่อมีรถใหม่ออก ให้ใช้ตรรกะ FIFO (First-In, First-Out) ค้นหาเรคคอร์ดเข้าที่เก่าสุดที่ยังมีรถเหลืออยู่ในลานมาตัดยอดออก
- **TASK_NOTES_PERMISSIONS**: การสร้างงาน (`createTaskNote`), การปิดงาน (`completeTaskNote`), และการดูรายการงานค้าง (`listTaskNotes`) ถูกจำกัดสิทธิ์ให้ดำเนินการและตอบคำถามได้เฉพาะผู้ใช้งานที่มีสิทธิ์ `ADMIN` หรือ `SUPER_ADMIN` เท่านั้น ผู้ใช้ทั่วไป (`USER` หรืออื่นๆ) จะไม่ได้รับอนุญาต
